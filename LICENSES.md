# Third-party licenses

Project code and original vector/painted UI assets require a publisher-selected project license before distribution.

Runtime packages are obtained from pub.dev and retain their own licenses:

- Flutter SDK — BSD 3-Clause
- flutter_riverpod / riverpod — MIT
- go_router — BSD 3-Clause
- sqflite and path — BSD-style licenses
- audioplayers — MIT
- path_provider — BSD 3-Clause
- shared_preferences — BSD 3-Clause
- uuid — MIT

The app contains no copied competitor artwork, commercial music, or proprietary logos. A final release must regenerate this inventory from the pinned lockfile and bundle every required notice.
